# Methods provenance

Paper 2 preserves the distinction between the initial analysis specification and the final fully inductive analysis.

The final publication analysis adds:

- fold-local gene eligibility;
- disjoint predictor/target panels with separate denominators;
- annotation-free molecular neighborhoods;
- training-owned state and target PCA controls;
- explicit exact-key lineage-exposure audit;
- independently tuned molecular and molecular-plus-history models;
- complete 76-member family-wise lineage calibration;
- complete 125-bank discrete diagnostic calibration;
- explicit deterministic hashing, clustering, nearest-neighbor, and null-stratification conventions.

The executable plan and frozen receipt are in `analysis/preregistration/`. Human-readable implementation clarifications are in `docs/methods/`.
