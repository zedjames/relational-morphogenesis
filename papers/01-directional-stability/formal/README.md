# Formal Publication Controls

The `standalone/` directory contains publication-control Lean files whose only external dependency is Mathlib.

Additional publication checks import broader private RMMO research modules. Those dependency-backed sources are not mirrored here. Their public authority is represented by `verification/formal_verification.json` and the exact completion commits in `docs/METHODS_PROVENANCE.md`.

A stable public Lean toolchain pin will be added at manuscript release. Only a stable release pin will be used.
