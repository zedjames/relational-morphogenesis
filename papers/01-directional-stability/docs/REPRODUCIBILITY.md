# Reproducibility

## Public finite-result verification

Run:

    make verify

The verifier checks source authority and decisive numerical surfaces using the Python standard library.

## Source authority

Raw MOSTA data are not mirrored. Public accession and raw-project identifiers are recorded in `data/source_manifest.tsv`; source hashes and biological sample authority are recorded in `data/authority/`.

## Analysis reconstruction boundary

The private development environment contains the large carrier-building and graph-generation pipeline. This public companion releases finite manuscript-facing outputs and independent consistency checks. Clean public source-reconstruction helpers may be added at final release where they can be separated from private infrastructure.

## Formal verification

Standalone publication-control theorem source is released under `formal/standalone/`. Dependency-backed checks are represented by formal verification receipts and exact completion commits.
