# Paper 3 manuscript-derived finite tables

This directory contains **14 machine-readable transcriptions of tables in the approved manuscript and detached supplement**. Entries reflect precisely the numerical precision printed in the scholarly text; they are not independent recomputations from the raw MELA resource or 1,024-draw reference banks.

Included: the 27 lane/pair construction authorities; q25 fibers; edge, target, degree and spatial reference summaries; matched-target and matched-edge pool diagnostics; coarse-state categories; construction, representation and domain-scale sensitivities; exact routewise composition; and existential bridge counts.

Use these files for citation, table reuse and consistency inspection. For a statistical reanalysis, use the original MELA archive and the complete bank/replay release once its real binary payloads are available.

The source-of-truth manuscript lives at `../../manuscript/RMMO_Paper3_Manuscript_preDOI.tex`, with detached appendix at `../../supplement/SupplementaryEvidence.tex`. See `../../docs/RESULT_MAP.md`.
