# Paper 3 — final publication reproducibility companion

Run `python verify_release.py` with the pinned `requirements.txt` libraries.
The verifier independently replays seven calibration-only banks through 33,792
exact graph draws and sparse-incidence scores, reproduces all 108 calibrated
component ranks and 72 aggregate/minimum ranks, verifies ordinary-file hashes,
and checks final source/figure authority. No Git, private paths, credentials,
raw H5TD acquisition or Lean build is required. Derived-input verification is
distinct from original raw-carrier extraction.

`manuscript/` and `figures/` contain the exact paper-specific publication names.
`rmmo_paper3_final08/` contains the frozen authorization, constants, calibration
banks and all-component original-versus-calibrated comparisons. Sibling parent
directories retain immutable inputs and historical provenance, not alternative
publication maxT conventions. Target-PCA is not a reported family and received
no new calibration. All 36 reported families use independent normalization and
unchanged inferential ranks. No support decision changed; no rescue was used.

Biological n=3; conditional draws are not biological replicates. The source
carrier retains MELA v1 / Zenodo 19892785 attribution and original rights; this
package does not blanket-relicense external data. Exact global descent,
representation invariance and population generalization are not established.
