# Frozen scientific dependencies

This directory preserves selected Final08 reviewer-release files byte-for-byte, including historical scripts and receipts. Supported public entry points are in the paper's `analysis/` directory. The original `README.md` and `verify_release.py` describe the older combined-manuscript layout; they remain frozen provenance and are not the public command.

Use `analysis/verify_numerical.py` for all seven calibration-bank replays and ranks/decisions, exact geometry/composition/bridge diagnostics and final figure authority. Use `analysis/verify_documents.py` for the approved manuscript and detached supplement. Original inferential draws, calibration constants, sampler code and comparison code are unchanged. Earlier combined manuscript/PDF/log files are explicitly absent; they are not numerical dependencies.
