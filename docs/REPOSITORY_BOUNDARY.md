# Repository Boundary

## Public material

This repository may contain manuscript source and PDFs, paper figures and figure inputs, source-data provenance, finite result tables, sensitivity/null summaries, release verification code, checksums, and standalone publication-control formalizations.

## Private material

The repository does not mirror the full private development environment. It excludes unrelated theorem libraries, generic orchestration systems, non-RMMO research programs, and exploratory branches outside a paper's release boundary.

## Formal verification boundary

Standalone publication-control Lean files may be released directly. Formal checks that depend on broader private research modules are represented publicly through theorem/build/axiom-audit receipts and exact completion commits.
